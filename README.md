# pydantic-ai-book-okf

An **[OKF](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) knowledge bundle** of [https://ai.pydantic.dev/](https://ai.pydantic.dev/) — ready for agents to read and for you to chat with.

```bash
pip install okf-kit
okf get pydantic-ai-book
okf chat pydantic-ai-book --provider ollama
```

Built and kept fresh with [okf-kit](https://github.com/vinodborole/okf-kit).
